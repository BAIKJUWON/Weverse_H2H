# 💗 Hearts2Hearts Weverse Archiver

> **하투하 사진은 못 참습니다.**
>
> Hearts2Hearts를 좋아해서 직접 만든 **비공식·비영리 개인 팬 아카이브 프로젝트**입니다.

**CARMEN · JIWOO · YUHA · STELLA · JUUN · A-NA · IAN · YE-ON 💞**

이 프로젝트는 Hearts2Hearts의 공식 팬클럽 **S2U(하츄)** 팬이 개인적인 덕질과 사진 정리를 위해 만든 프로그램입니다.

게시물이 쌓이다 보니 예전에 봤던 사진을 다시 찾는 일이 생각보다 귀찮았습니다.

그래서

> **“내가 정상적으로 볼 수 있는 하투하 사진을 개인 소장용으로 깔끔하게 정리해 보자.”**

라는 생각으로 만들기 시작했습니다.

이 프로그램은 사용자가 직접 로그인한 Weverse 세션을 이용하여 Hearts2Hearts 커뮤니티의 게시물을 확인하고, 사용자가 정상적으로 열람할 수 있는 게시물에 포함된 이미지를 멤버별 폴더로 정리하여 **개인 보관용으로 저장하는 도구**입니다.

# 🩷 왜 만들었나요?

이유는 단순합니다.

**하투하를 좋아해서 만들었습니다.**

위버스에 올라오는 사진을 하나씩 저장하다 보면 다운로드 폴더에 사진이 뒤섞이기 시작합니다.

나중에는

> “이거 지우 사진이었나?”

> “이안이었나?”

> “단체사진이었나?”

하면서 다시 찾아보게 됩니다.

그래서 직접

**Weverse 확인 → 작성자 확인 → 멤버 분류 → 사진 저장 → 중복 검사 → 멤버별 정리**

과정을 하나의 프로그램으로 묶었습니다.

포트폴리오를 만들기 위해 억지로 주제를 정한 프로젝트라기보다는 **제가 실제로 필요해서 만든 덕질 자동화 프로그램**입니다.

덕질도 데이터 정리가 필요합니다. 😎

# 🚀 설치

## 1. 저장소 받기

```bash
git clone https://github.com/BAIKJUWON/Weverse_H2H.git
cd Weverse_H2H
```

## 2. Python 패키지 설치

```bash
pip install -r requirements.txt
```

## 3. Google Chrome 설치 확인

이 프로그램은 시스템에 설치된 **Google Chrome**을 사용합니다.

## 4. 선택 사항: 개인 설정 만들기

기본값으로 실행할 수 있으며, 개인 저장 위치 등을 지정하고 싶다면

```text
config.example.json
```

파일을 복사하여

```text
config.json
```

으로 만든 뒤 수정하면 됩니다.

`config.json`에는 개인 PC 또는 NAS 경로가 포함될 수 있으므로 `.gitignore`에 등록되어 있습니다.

멤버 식별 정보 등 실행 중 필요한 일부 데이터는

```text
data/members_runtime.json
```

등 런타임 영역에 별도로 생성됩니다.

# ▶ 실행

## GUI 실행

```bash
python main.py
```

실행 후:

1. `Chrome 열기`를 누릅니다.
2. 열린 Chrome에서 사용자가 직접 Weverse에 로그인합니다.
3. 사용자가 정상적으로 접근할 수 있는 Hearts2Hearts 커뮤니티를 이용합니다.
4. 프로그램으로 돌아옵니다.
5. `사진 저장 시작`을 누릅니다.

**프로그램이 사용자의 비밀번호를 대신 입력하거나 인증 절차를 우회하지 않습니다.**

로그인이 만료된 경우에는 사용자가 직접 다시 로그인해야 합니다.

서비스 정책이나 관련 법령이 변경되는 경우 해당 변경사항을 우선하여 따라야 합니다.
